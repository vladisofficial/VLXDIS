# VLXDIS v1.6.0 - Telegram Account Snoser

Мощный инструмент для массовой отправки жалоб на аккаунты Telegram через MTProto API (слой 181).

## Возможности

- Массовая отправка жалоб через множество аккаунтов-доноров
- Поддержка SOCKS5 прокси для анонимности
- Управление через консольное меню или Telegram-бота
- OSINT-поиск: Sherlock, поиск по номеру, ID, email, утечки
- Выбор типов жалоб (Spam, Violence, Pornography, Child Abuse, Copyright, Other)
- Настраиваемые задержки, количество жалоб, параллельные сессии
- История сносов с детальными отчётами
- Режим разработчика с горячей перезагрузкой кода
- Система администрирования бота (суперадмины, админы)

## Установка

### 1. Клонирование
```
git clone https://github.com/vladisofficial/VLXDIS.git
cd vlxdis
```

### 2. Установка зависимостей
```
pip install -r requirements.txt
```

### 3. Настройка API
1. Зайдите на https://my.telegram.org
2. Создайте приложение (API Development Tools)
3. Скопируйте `api_id` и `api_hash` в `config.json`

## Быстрый старт

### Консольное меню
```
python main.py
```

### Telegram-бот
1. Создайте бота через @BotFather
2. Вставьте токен в `bot.py` → `BOT_TOKEN = "ВСТАВЬ_ТОКЕН"`
3. Запустите:
```
python bot.py
```
4. В Telegram отправьте `/start` вашему боту

## Подготовка к сносу

### 1. Добавление сессий (аккаунтов-доноров)
- Купите аккаунты Telegram (MarketGram.io, CrazyShops)
- Получите строки сессий (session_string)
- Вставьте в файл `session_strings.txt` (одна строка = одна сессия)
- Или используйте `/addsession` в боте

### 2. Добавление прокси
- Купите SOCKS5 прокси (Proxy6.net, Asocks.io)
- Формат: `ip:port:username:password`
- Вставьте в файл `socks5_proxies.txt` (один прокси = одна строка)
- Или используйте `/addproxy` в боте

### 3. Проверка
- В меню: пункт 5 → 3 (проверить сессии)
- В боте: `/sessions` и `/proxies`

## Запуск сноса

### Через консоль
1. Выберите пункт 1 "Начать новый снос"
2. Введите цель: `@username` или `+79123456789`
3. Выберите типы жалоб (рекомендуется 7 - ALL)
4. Укажите количество жалоб
5. Укажите количество параллельных сессий
6. Введите текст жалобы (или Enter для стандартного)
7. Укажите задержки (0.5-2.0 сек)

### Через бота
1. `/snos` — начать новый снос
2. Следуйте инструкциям бота
3. `/status` — проверить прогресс
4. `/stop` — остановить снос

## OSINT-поиск

Встроенный модуль для поиска информации о цели:

| Тип поиска | Источник |
|------------|----------|
| Username по соцсетям | Sherlock (20+ сайтов) |
| По номеру телефона | Telegram API |
| По ID | Telegram API |
| Email в утечках | HaveIBeenPwned + BreachDirectory |
| Слитые базы | LeakCheck Public API |

## Управление ботом

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/snos` | Админ | Запуск сноса |
| `/status` | Все | Статус сноса |
| `/stop` | Все | Остановить снос |
| `/addsession` | Админ | Добавить сессию |
| `/addproxy` | Админ | Добавить прокси |
| `/addadmin ID` | Суперадмин | Добавить админа |
| `/adduser @name` | Суперадмин | Добавить по username |
| `/removeadmin ID` | Суперадмин | Удалить админа |
| `/adminlist` | Админ | Список админов |

## Рекомендации

- Не ставьте больше 50 жалоб на 1 аккаунт за раз
- Используйте 1 прокси на 2-3 аккаунта
- Выбирайте прокси из разных стран
- Проверяйте сессии перед сносом
- Используйте username цели (не ID) для гарантированного резолва
- NFT-username не поддерживаются
